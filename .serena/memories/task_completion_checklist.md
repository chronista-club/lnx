# タスク完了時のチェックリスト

## 必須確認項目

### 1. テスト実行
**Rust側**:
```bash
cargo test --all
cargo fmt --check
cargo clippy
```

### 2. ビルド確認
```bash
# ワークスペース全体のビルド
cargo build --all
cargo build --release
```

### 3. コードフォーマット
```bash
cargo fmt
```

### 4. Git状態確認
```bash
git status
git diff  # 変更内容の最終確認
```

### 5. Linear課題の更新
- 作業完了時はLinearの課題ステータスを更新
- 必要に応じてコメントを追加
- 関連するworktreeの削除を確認

## 推奨事項

### ドキュメント更新
- 大きな変更時はREADME.mdの更新を検討
- 新機能追加時は使用方法を文書化

### パフォーマンス確認
- オーディオ処理の遅延測定（目標: <5ms）
- メモリ使用量の確認

### セキュリティチェック
- 秘密情報がコードに含まれていないか確認

## 注意事項
- **コミットは明示的に指示された場合のみ実行**
- lintツールが設定されていない場合は、ユーザーに確認
- エラーや警告がある場合は必ず解決してから完了

# LNX Specification

**実装を超えた、コンセプトと哲学の生きたドキュメント**

## 目的

このディレクトリは、LNXプロジェクトの**本質**を記述する場所です。

- 💭 **コンセプト**: なぜこのプロジェクトが存在するのか
- 🎯 **ビジョン**: どこに向かっているのか
- 🧭 **哲学**: どのような価値観で設計されているのか
- 📐 **原理原則**: 実装の根底にある不変の考え方

### docs/ との違い

| ディレクトリ | 目的       | 内容                   | 変更頻度           |
| ------------ | ---------- | ---------------------- | ------------------ |
| **spec/**    | 本質の記述 | コンセプト、哲学、原理 | 低い（進化的）     |
| **docs/**    | 実装の記述 | 技術文書、API、使い方  | 高い（実装に追従） |

`spec/`は実装の詳細から独立しており、プロジェクトの「魂」を表現します。
`docs/`は具体的な実装や使用方法を記述します。

## 原則：生きたドキュメント

このspecは**生きたドキュメント**であり、以下の原則に従います：

### 1. 進化する

- プロジェクトの成長と共に進化する
- 新しい洞察や学びを反映する
- 過去の判断を振り返り、より良い理解へと深化する

### 2. 実装から独立する

- 特定の技術やライブラリに依存しない
- 「何を」実現したいかに焦点を当て、「どのように」は二次的
- 実装が変わっても本質は変わらない

### 3. 対話を促す

- 読者に問いかける
- なぜそうなのか、を常に問う
- 異なる視点を歓迎する

### 4. 簡潔かつ深い

- 冗長な説明を避ける
- 本質に迫る
- 一文一文に意味を持たせる

## ドキュメントフォーマット

各specファイルは以下の構造を推奨します：

```markdown
---
title: タイトル
version: 1.0.0
date: 2025-11-05
status: draft | stable | deprecated
---

# タイトル

## なぜ (Why)

この概念が存在する理由、背景、動機

## 何を (What)

この概念が表現するもの、本質

## 原則 (Principles)

この概念を実現するための不変の原則

## 例 (Examples)

具体的な例、比喩、メタファー

## 反例 (Anti-patterns)

この概念に反するもの、避けるべきこと

## 関連 (Related)

関連する他のspec、概念

## 履歴 (History)

このspecの進化の記録
```

## コミットメッセージ規約

specへの変更は以下のプレフィックスを使用：

- `spec(concept):` - コンセプトの追加・更新
- `spec(refine):` - 既存specの洗練
- `spec(meta):` - spec体系自体の変更

## 貢献ガイドライン

### specを書く時

1. **問いから始める**: なぜこれが重要なのか？
2. **本質を追求する**: 実装の詳細ではなく、本質を書く
3. **簡潔に**: 冗長な説明を避け、一文一文に意味を持たせる
4. **例を示す**: 抽象的な概念には具体例を添える
5. **進化を恐れない**: 完璧を求めず、まず書く。後で洗練する

### specをレビューする時

1. **本質的か**: 実装の詳細ではなく本質を語っているか？
2. **明確か**: 読者に伝わるか？
3. **一貫性**: 他のspecと矛盾していないか？
4. **価値**: これは本当に書く価値があるか？

## ステータス定義

- **draft**: 草案段階、議論中
- **stable**: 安定版、プロジェクトの基盤として機能
- **deprecated**: 非推奨、新しいspecに置き換えられた

## LNXの3つの柱

LNXは以下の3つの柱の上に成り立っています：

1. **Low-Latency** - 低遅延
2. **High-Quality** - 高品質
3. **Human-Friendly** - 人に優しい

これらは単なるスローガンではなく、すべての設計判断の基準となる原則です。

## ヴィジョンクリエイティブツール

LNXは**ヴィジョンクリエイティブツール**——ビジョンを創造するツールです。

**Vision Creative Tool**の3要素：

- **Vision（ビジョン）** - 内なる想像力、心に描く理想
- **Creative（クリエイティブ）** - 創造的、能動的な行為
- **Tool（ツール）** - すべての人が使える道具

内なるビジョンを、視覚的な表現として世界に顕現させる。
